## Objective

Three remaining vendor references that reach the network or GitHub on the user's behalf move under `src/shared/product-egress-policy.ts`:

- **Plugin marketplace → disable the official source**: V1 seeds no official marketplace; the marketplace feature stays, the user may add sources manually.
- **Skills install source → replace**: the bundled skills (`skills/` in this repository) are installed into agents from `https://github.com/LaPaGaYo/Axiom` (D21 publish source), never from the upstream repository.
- **Star prompt → disable**: no "star us on GitHub" nag, no `gh` call to check or create a star.

Not in this task: cloud account/relay/push/artifact/skill-cloud (M0-06a); copy, README, locale catalogs (M0-05); `mobile/`, `cloud/` (M0-07).

## Design

Extend `ProductEgressPolicy` (and its pinned test) with:

```ts
/** Official plugin marketplace git source seeded at startup; null = no official source. */
readonly officialPluginMarketplace: { readonly owner: string; readonly repository: string; readonly gitUrl: string } | null
/** Repository agents install the bundled skills from. */
readonly skillsRepositoryUrl: string
/** Repository the star prompt targets; null = no star prompt. */
readonly starPromptRepository: string | null
```

V1 values: `officialPluginMarketplace: null`, `skillsRepositoryUrl: 'https://github.com/LaPaGaYo/Axiom'` (derive from `updateFeed`, do not duplicate the slug), `starPromptRepository: null`.
