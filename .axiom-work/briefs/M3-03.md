1. **Path patterns** — new `src/shared/axiom-contract/path-patterns.ts` (pure, no Node APIs), one semantics for `scope.allowedPaths` and `dangerousPathPatterns` (D65 2026-10-24 revision ① ②):
   - `normalizePathPattern(entry: string): string | null` — replace `\` with `/`, collapse repeated `/`, drop leading `./` segments and a trailing `/`; `''` after that is `.`. Return `null` (invalid) for an absolute entry (leading `/`, or a Windows drive such as `C:`) and for any entry with a `..` segment.
   - `matchesPathPattern(path: string, pattern: string): boolean` — `path` is a repository-relative POSIX path as Git prints it; `pattern` is normalized first (invalid → `false`). `.` matches every path. Otherwise compare by `/`-separated segments: `**` as a whole segment matches zero or more segments (consecutive `**` collapse); in any other segment `*` matches any run of characters (possibly empty) and `?` exactly one character, never across `/`; every other character is literal (no character classes, braces, negation or escapes — `app/[id]/page.tsx` names that literal path). The pattern matches when it matches the whole path **or a leading run of its segments** (so an entry covers that path and everything below it). Case-sensitive; dot-files are not special.
   - `isExplicitlyInScope(path: string, dangerousPattern: string, allowedPaths: readonly string[]): boolean` — true when some valid entry `e` with `matchesPathPattern(path, e)` also satisfies `matchesPathPattern(normalizePathPattern(e), dangerousPattern)`, i.e. the entry itself, read as a literal path, matches the dangerous pattern. `.`, `src/`, `**` are never explicit; `package.json`, `src/storage/AGENTS.md`, `.github/workflows/` and `**/package.json` are explicit for the paths they cover.
   - Implementation: segment recursion with memoisation on (pattern index, path index); per-segment matching with a linear wildcard matcher or a regular expression built only from that segment with every other character escaped. A pattern of 30 `**` segments against a 200-segment path must return quickly (test it).

4. **Candidate diff** — new `src/main/axiom/verification/candidate-diff.ts` (D64 revision, three-dot diff). Input `{ cwd, missionId, candidateCommitSha, patchByteLimit? }` (`cwd` = the verification worktree; default limit 32 MiB). Every Git call goes through `src/main/git/runner` (`gitExecFileAsync`, `gitStreamStdout`) with `gitOptionsForWorktree(cwd)`; read-only; SHAs, not branch names, after step 1.
   1. `rev-parse --verify --quiet refs/heads/axiom/integration/<missionId>^{commit}` → integration base SHA; failure → `{ ok: false, reason: 'integration_base_unavailable' }`.
   2. `merge-base <baseSha> <candidateCommitSha>`; non-zero exit (no common ancestor) → `merge_base_unavailable`.
   3. `diff --no-color --no-ext-diff --no-textconv --no-renames --name-status -z <mergeBase> <candidate>` → `{ status, path }[]` from the NUL-separated status / path pairs (keep the status letter as Git prints it; an odd token count → `diff_unavailable`). `--no-renames` matters: a rename appears as a deletion plus an addition, so an out-of-scope source path cannot hide behind its new name.
   4. `diff --no-color --no-ext-diff --no-textconv --no-renames --submodule=short -U0 <mergeBase> <candidate>` streamed with `gitStreamStdout`; stop at `patchByteLimit` and report `patchComplete: false` with no added text for any file (steps 1–3 still stand). Parse: split into sections at lines that start with `diff --git `; the section count must equal the step-3 entry count (else `diff_unavailable`) and section *i* belongs to entry *i* (same diff machinery, same order — do not parse paths out of headers, Git quotes unusual names). In a section, ignore every line before the first line that starts with `@@`; after it, a line starting with `+` is an added line (strip one `+`); `-`, `\` and `@@` lines are skipped. A section with a `Binary files ` line and no hunk is binary (listed, never scanned).
   5. Result `{ ok: true, integrationBase: { branch, sha }, mergeBase, candidateCommitSha, changes, addedText: Map<path, string> (added lines joined by '\n'), binary: string[], patchComplete }`. Any other Git failure → `diff_unavailable`. Never persist or log raw Git output.
