## Objective

M0 removed or disabled every upstream vendor egress (updater feed, changelog/nudge, kill-list, feedback and diagnostics upload, telemetry, cloud auth/relay/push, artifact and skill sharing, marketplace, star prompt). This task turns that into evidence that survives future changes:

1. **Build-time identity test** — one focused vitest file pins the product build constants that the egress policy depends on.
2. **Runtime egress capture** — a Playwright e2e launches the built desktop app headless with every network stack pointed at a local *recording* proxy, lets it cold-start and idle, and asserts that no request targeted a vendor host. The recorded host tally is archived as an M0 deliverable.

The vendor-egress ratchet (M0-01, `config/scripts/check-vendor-egress-ratchet.mjs`) already covers the "no new needle in source" part of the mapping's strategy; item (3) of §7 (`verify:egress-allowlist`) is therefore superseded — say so in the mapping, do not build it.
