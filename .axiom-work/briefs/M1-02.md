3. `src/shared/axiom-contract/plan-proposal.ts` — the PlanRevision **proposal** contract a Planner or the CLI submits: `{ goalRevisionId, milestones: [{ id, title, exitCriteria[] }], tasks: TaskSpec[], edges: TaskEdge[], risks: [{ id, description, mitigation? }], provenance }` and `validatePlanProposal(proposal): { ok: true, order: string[] } | { ok: false, errors: PlanProposalError[] }` that, after zod parsing, rejects: duplicate task ids; an edge whose endpoint is not a task in the proposal; self-edges; duplicate edges; a cycle (report the cycle's task ids); a `milestoneId` that names no milestone; and, as a warning-grade error only if the caller asks (`{ requireParallelRoots: 3 }`), fewer than N root tasks (charter §9: a Goal decomposes into 8–15 Tasks with ≥ 3 independently ready). `order` is a deterministic topological order (stable: ties broken by task id) so M1-05 can materialize Tasks in one pass. Pure functions; no I/O.
