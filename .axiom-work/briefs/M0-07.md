## Objective

Axiom V1 neither builds nor operates the upstream vendor's cloud (relay/push/login infrastructure under `cloud/`) nor its mobile companion app (`mobile/`). Per D33:

- `cloud/` is **deleted** together with its CI (`.github/workflows/cloud-*.yml`, `.github/actions/cloud-sql-rollout-lease/`, the `CODEOWNERS` lines) — nothing under `src/`, `config/` or `tests/` depends on it.
- `mobile/` **stays in the tree** (the desktop build and several root gates reference it) but is declared non-shipped: its release/CI workflows (`.github/workflows/mobile.yml`, `mobile-android-release.yml`, `mobile-ios-release.yml`, `.github/actions/install-mobile-dependencies/`) are removed, the PR workflow no longer installs mobile dependencies or builds the mobile web app bundle, and the vendor-egress ratchet excludes `mobile/**` as non-shipped code (the exclusion list lives in `config/scripts/check-vendor-egress-ratchet.mjs`; add the directory there with a one-line "why").
