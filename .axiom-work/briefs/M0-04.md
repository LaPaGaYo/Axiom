## Objective

Axiom V1 has **no product telemetry** (D25). Remove the PostHog transport and dependency so that no telemetry bytes can leave the machine, while keeping the in-process event vocabulary and validation so the 27+ `track()` call sites, the typed event map and the validator tests stay as they are:

- `track()` remains the single entry point: it still validates against the event schema and applies the burst caps (so a malformed event is still caught in tests), then **drops** the event. No sink, no queue, no network.
- The consent machinery stops asking the user for something that no longer exists: the first-launch telemetry banner and the "Share anonymous usage data" toggle disappear from the UI. The persisted `settings.telemetry` shape stays (additive compatibility; a future opt-in sink can reuse it).
- `posthog-node` is gone from `package.json`, the lockfile and the packaged runtime module list; the `ORCA_POSTHOG_WRITE_KEY` build constant, the CI secret wiring and the post-packaging constant check are deleted.
- `ORCA_BUILD_IDENTITY` stays (the diagnostics endpoint resolver still distinguishes official builds).

Local diagnostics (bundle collection, crash minidumps, the Privacy pane's diagnostics sections) are **not** telemetry and must keep working unchanged.
