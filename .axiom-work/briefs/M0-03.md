## Objective

Axiom ships with **no vendor network egress**. This task introduces one typed, deterministic *product egress policy* and makes every non-telemetry vendor fetch obey it:

- **updater feed → replace**: releases come from GitHub `LaPaGaYo/Axiom` (D21) for *every* channel; automatic/background update checks are **off** in V1 (the user's explicit "Check for updates…" still works).
- **changelog / nudge → disable**: no request is made; the UI simply has no "what's new" content.
- **plugin kill-list → disable**: no request; the service behaves as if the remote list is empty (the local store still works).
- **feedback and crash-report upload → disable**: no request; the renderer does not offer the feedback entry; the main-process lane refuses with a typed failure even if invoked directly.
- **diagnostics upload → disable** for official builds: the build-time pinned endpoint is gone; the developer `ORCA_DIAGNOSTICS_TOKEN_URL` env override for unofficial builds stays as-is.

Telemetry (PostHog) is **not** part of this task — M0-04 removes it. Login/relay/push, artifact share, skills source, marketplace and the star prompt are M0-06. Human-facing copy, README and notices are M0-05.

## Design (follow it; propose changes in the report, do not improvise)

1. Create `src/shared/product-egress-policy.ts` (pure constants, no Electron/Node imports, importable from main, renderer and CLI):

   ```ts
   export type ProductEgressPolicy = {
     /** GitHub repository that serves release assets and the prerelease feed. */
     readonly updateFeed: { readonly owner: string; readonly repo: string }
     /** When false, the updater never schedules startup/background/wake checks; menu-initiated checks still run. */
     readonly automaticUpdateChecks: boolean
     readonly changelogJsonUrl: string | null
     readonly changelogPageUrl: string | null
     readonly nudgeUrl: string | null
     readonly pluginKillListUrl: string | null
     readonly feedbackApiUrl: string | null
     /** Official-build pinned endpoint for diagnostic upload tokens; null = no upload in official builds. */
     readonly diagnosticsTokenUrl: string | null
   }
   export const PRODUCT_EGRESS_POLICY: ProductEgressPolicy = {
     updateFeed: { owner: 'LaPaGaYo', repo: 'Axiom' },
     automaticUpdateChecks: false,
     changelogJsonUrl: null, changelogPageUrl: null, nudgeUrl: null,
     pluginKillListUrl: null, feedbackApiUrl: null, diagnosticsTokenUrl: null
   }
   export const productReleaseRepositorySlug = (): string => `${PRODUCT_EGRESS_POLICY.updateFeed.owner}/${PRODUCT_EGRESS_POLICY.updateFeed.repo}`
   ```
   Add `src/shared/product-egress-policy.test.ts` asserting exactly these V1 values (every nullable endpoint is `null`, `automaticUpdateChecks === false`, slug `LaPaGaYo/Axiom`), so a future change to the policy is a visible, tested decision.

2. **Every consumer reads the policy; no consumer keeps a vendor literal.** A `null` endpoint means *return the "nothing available" value immediately without touching `net`/`fetch`* — not "fetch and ignore errors".
