## Outcome

After this Task a Mission can plan with Claude Code and work with Codex, or the reverse, chosen per role by policy, defaulting to different providers. The Claude Worker runs on the same headless runner as Codex (`claude -p --output-format stream-json`, PTY wrapper, host submission on exit, sandboxed, no prompts possible); the Claude Planner runs on Orca's structured (Agent SDK) channel with Axiom-authored permission rules and auto-denied prompts. Every Attempt records the Claude execution combination; nothing the user installed in their own Claude home is inherited by default. `claude` stays `provisional` in `certified-providers.ts` — the verifier's host smoke flips it (D57), as for codex.
