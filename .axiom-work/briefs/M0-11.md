## Objective

M0's exit standard (architecture §20) requires "no RPC/CLI name collision" and lists "the empty `axiom.*` namespace and the CLI command names registered" in M0's scope. Make the namespace exist in the RPC manifest with one introspection method, publish the reserved names from the shared contract, and prove by tests that nothing in the upstream-derived runtime or CLI uses them. Nothing else: no Mission objects, no migrations, no CLI stub commands (a reserved name is proven free by a test, not by shipping a placeholder command that prints "not yet").
