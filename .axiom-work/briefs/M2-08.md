# Task M2-08 — RecoveryService (Attempt subset): liveness reconciliation, retry/exhaustion settlement, Mission pause/cancel over active Attempts, bounded consumer retry

You are a Worker on the Axiom project (a product fork of Orca). Read `AGENTS.md` (Execution Kernel Boundary, Remote Execution and Process State, Independent Verification, Code Placement, Lazy Senior Dev Mode), `docs/ARCHITECTURE.md` §16.1 (Reconciliation) and §9 (`RUNNING → NEEDS_FIX / BLOCKED`), `docs/reference/control-plane.md` §4 "Attempt launch（M2-05）", §"Submission settlement（M2-07）" and §8 "Mailbox 与恢复", and the current code named below before editing.

## Objective

Make the Control Plane converge on execution-host truth after crashes, disconnects and restarts, without ever inventing process state:

1. `RecoveryService.reconcileAttempts()` replaces the M1 stub `'no_attempts_in_m1'`: at boot, periodically, and when the kernel reports a worker exit, every Attempt whose Task is still `RUNNING` is compared with the kernel's worker row and the execution host's liveness verdict; the Task is moved only through the existing stage machine.
2. One shared settlement for "this Attempt ended without a Submission": `RUNNING → NEEDS_FIX`, then `NEEDS_FIX → READY` (retry budget left) or `NEEDS_FIX → BLOCKED` (`retry_budget_exhausted`). The M2-05 launcher's `fail()` is generalized onto it (it currently stops at `NEEDS_FIX` or goes straight to `BLOCKED`).
3. `unverifiable` is tolerated, not punished: the Task stays `RUNNING` and no second Attempt is started; only after `policy.unverifiableToleranceMinutes` is the Attempt abandoned through the kernel with an evidence Artifact.
4. `mission pause` admits nothing (already true) while running Attempts finish; `mission cancel` stops live Attempts and abandons unreachable ones through kernel services, then requests workspace release.
5. The run-mailbox consumer gets bounded exponential retry with a durable escalation, and an indexed message-audit lookup instead of scanning the Mission's whole audit per batch (D46 leftovers).
