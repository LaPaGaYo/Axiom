## For Henry to know

- **What a person can see.** A Mission that becomes `READY_FOR_APPROVAL` from now on has a completion report. There is no page for it yet (M4-11): today it is read as JSON — `axiom.mission.show` gives `finalization.reportArtifactId` and `reportSha256`, `axiom.artifact.read` returns the file; the existing CLI commands for artifacts list and print it too (I read those handlers; I did not run them). The gate shows eight items instead of seven.
- **One behaviour change.** A question nobody answered on a Task that is already integrated or canceled no longer keeps the Mission in `FINALIZING`; it is listed in the report under that Task. Because every Task is settled when finalization runs, the question item now fails only for a blocking Approval. This is the narrowing the M4-6a record announced.
- **Verifier's details, yours to overturn** (they were in the brief and the plan row): the report is JSON only, format version 1, and any change of a field is a new version; it holds no time of generation, so the same facts always give the same file and the same hash; `limitations_recorded` checks that each integrated Task has the Worker's submission stored, not what its lists say; the report repeats stored text (summaries, rationales, questions, commands) and is readable like every artifact of the Mission, by an agent session of that Mission too.
- **Limits** (all in the new section of `control-plane.md`): a Mission that became ready under M4-6a has a record without a report and nothing writes one for it; a report that the comparison rejected or a later run replaced stays in the store unreferenced, and nothing deletes artifacts; a report over 8 MiB cannot be stored and finalization then stops as `finalization_unavailable`; an older build that opens this database cannot read a `ready` record with a report, a gate of eight items or the new kind (nothing is released yet); `decisions` is a list of ids and no product code writes a Decision yet; an Attempt without a launch event has no channel or posture in the report; no Markdown, no page and no export command until M4-11; the delivery part of the report and a second report after delivery are M4-8's.
