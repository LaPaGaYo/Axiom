- **Kernel orchestration verbs are refused on such a database even for Runs no Mission owns**, and so are the restricted requests of an agent session that holds a dispatch. The guard cannot ask who owns a Run without the Control Plane, and it refuses rather than guesses. This follows the verifier's reading of pending item 9 of 2026-11-16, which Henry answered ("Mission 相关的操作和内核的编排写操作都会被拒绝"); it is his to overturn.
- **The check is made once**, when a process first asks for the Control Plane of a database. A Control Plane that exists is not stopped when another process raises the stamp later.
- **The database is still opened**, and the kernel's and Axiom's "create when missing" DDL still runs on it. An older build can therefore add an object a newer schema no longer has; it does not change or remove one. SCHEMA-1's rule for later steps (never delete or redefine what an older build's DDL creates when missing) is what keeps that harmless.
