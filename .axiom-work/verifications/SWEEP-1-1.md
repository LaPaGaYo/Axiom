## For Henry to know (none of it needs a decision now)

- The sweep makes one limit of M4-2b more visible: an integration request that ended `failed` while its Task stayed `INTEGRATION_READY` is asked again by every round, now once a minute, each time with three tries and a merge and regression per try. Reading the code again for this Task: three failed tries normally end in `abandonIntegration`, which blocks the Task, so this state needs a second fault (the settlement itself failing, or the process stopping between the two). No bound was added; the brief kept that out of scope.
- A round that fails for a lasting reason — a repository that cannot be read, say — now fails and warns once a minute instead of once.
- The sweep does nothing under e2e unless a spec sets `AXIOM_E2E_RUN_SWEEP=1`; no spec does yet, so the Mission specs exercise the product exactly as before and the sweep is covered by unit tests only.
