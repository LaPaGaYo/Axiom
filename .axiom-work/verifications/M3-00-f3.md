Upstream Orca (`upstream/main` `ce2d60834c`) rewrote this path after our fork point `3eb1adec20`: `sendStructuredWorkerPreamble` now goes through `sendAgentTurn` ("waits the start out") and returns `'accepted' | 'pending'` — pending = "held for the agent", not a failure (commits touching the file: `bfe476f922` "a message is accepted, then delivered" #22821, `0c4e26e1d4` #24901, `9fdd90ffa7` #22972, `418c601d20` #26724, `dfffb302f8` #26776, `b3048a2b9c` "Wait for agent readiness without blocking native chat" #27925, …).
