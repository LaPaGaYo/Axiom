- Planner runs and TUI Attempts are not metered; ended TUI Attempts record unavailable with zeros.
- Every pass re-reads up to 32 MiB of Codex rollout tail and 64 MiB of Claude events; there is no offset cache. Cut windows report partial.

- Codex sub-agent threads are not counted.

- Nothing is enforced: no token-driven stop, settlement, BLOCKED(budget), admission refusal, task.adjust change or remaining-budget prompt. All remain M3-06-3-3b.
- Finalization is immutable, including partial/unavailable evidence. The implementation does not claim absent evidence proves no spending.
- Host Electron acceptance, immutable Candidate verification and final milestone completion remain pending. Preserve this assigned branch and working tree for the verifier; do not merge directly into protected branches.
