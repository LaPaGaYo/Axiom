## Limitations, risks, and differences

- A finished Attempt with marker 0 and a complete report is not submitted here in V1. Its work is preserved and a new Attempt continues it in a new worktree and fresh session.
- An Attempt that had failed by itself before losing its daemon gets one uncounted retry when this rule owns settlement. Existing backoff and the three-in-a-row interruption limit remain.
- If the exit path commits before the kernel verdict, its ending stands. A nonzero ordinary Worker failure, including this fixture's crash, remains counted. The exit classifier's existing provider-interruption exceptions are unchanged.
- If the kernel verdict overtakes the exit path during its awaits, that pass still fails and settlement occurs one pass later. Boot ordering and classification of signal exits are intentionally unchanged.
- The new e2e reaches the state through the fixture's hold and atomic marker write, not through signal timing. Both launches keep the hold, so the successor's own ending is held and no Submission is awaited.
- `electron-process-shutdown.ts` and its kill order are unchanged. The first test's timing race still exists; with a lost-daemon verdict, a wrapper marker now ends in the interruption that test expects. The host verifier still needs to repeat the forced 400 ms experiment.
- The kernel verdict proves terminal loss, not process exit. Surviving descendants and partially written work remain possible; the successor gets a different worktree and final Candidate verification remains necessary. No in-place recovery is enabled by `exitMarker`.
- There is no runtime write-scope enforcement for CLI Workers; this task relies on the final diff allowlist and independent verification, as required by the repository.

Necessary verification differences: the sandbox prohibits socket listening and `/bin/ps` execution. The broad Bun run therefore failed in unchanged `recording-proxy.unit.test.ts` (11 tests: loopback bind failures and a CONNECT timeout), `remote-skill-cloud-fixture.unit.test.ts` (1 test: origins cannot bind), and `electron-process-shutdown.unit.test.ts` (2 tests: descendant/grace expectations).
