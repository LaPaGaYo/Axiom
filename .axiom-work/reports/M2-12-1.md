## Exact rule c′ preconditions

All five must hold:

1. `observation.status === 'live'`.
2. `observation.exact === true`.
3. `observation.terminal !== null` (PTY lane).
4. The pre-inspection worker row has `state === 'ready'` (readiness has settled).
5. `await ctx.runtime.confirmTerminalShellForeground(observation.terminal.handle) === true`.

The result is `{ exited: true, evidence: 'shell_foreground' }`; otherwise `{ exited: false }`.
Nonqualifying observations do not call the accessor. Each qualifying observation makes exactly one fresh call, using the terminal handle. No cache, counters, title, hook or agent-status inference is added. The existing daemon supplies process-table evidence: spawned shell in the foreground with no stopped descendant; on Windows, shell alone in the job.
