| Skill-share link parsing | `app.orca.dev`, `share.onorca.dev`, local and app URLs | `skillShareHosts: []`; bare identifiers only; all URLs rejected, including loopback and app links | No existing share-host env flag; an explicit future policy host list is required for URL parsing; bare IDs can use a configured service | `skill-share-link.ts`; existing SkillInstallDialog unconfigured result handling |

The requested artifact host restriction is deliberately stricter than an arbitrary env URL: with a null policy origin, a packaged build cannot enable artifact/skill cloud against a remote host using only an environment variable. Unpackaged loopback overrides are tested. A future packaged cloud service requires a policy-host decision. No new env escape hatch was introduced.
