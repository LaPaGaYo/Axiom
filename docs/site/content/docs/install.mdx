## Pre-release: build from source

Axiom is pre-V1 and has no releases yet. Clone the [Axiom repository](https://github.com/LaPaGaYo/Axiom), then run the following from its root, using Node.js 24 and the pnpm version declared in `package.json`:

```sh
pnpm install
pnpm dev
pnpm tc
pnpm test
pnpm lint
```

See the repository [Developing instructions](https://github.com/LaPaGaYo/Axiom#developing).
